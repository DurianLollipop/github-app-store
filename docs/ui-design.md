# Orbit TV 视觉与动效规范

本轮以用户提供的 Apple TV 风格参考图为依据，改造现有原生 Compose 首页。业务、目录来源、下载、安装和介绍阅读逻辑继续沿用。项目分析、文件范围与性能边界见[首页改造方案](home-redesign-plan.md)。

## 布局与材质

| 原界面 | 当前界面 | 调整目的 |
| --- | --- | --- |
| 左侧常驻竖栏 | 顶部居中的悬浮导航胶囊 | 释放横向空间，接近参考图的视线结构 |
| 大宣传卡片、银色球体 | 左侧单行标题、右侧蓝紫粉丝绸曲线 | 用留白和背景光影组织层次 |
| 横向信息卡片、42dp 图标 | 六列横向圆角卡片、左上高光、居中名称 | 让应用本身成为主角，遥控器定位更直接 |
| 每张真实 Logo 都有品牌渐变底 | 真实 Logo 使用中性容器，缺图才使用字母占位 | 保留原图颜色与比例 |
| 统一约 1.025 倍聚焦 | 首页图标 1.08 倍聚焦、轻微抬升、柔光 | 增强大屏空间感和当前操作位置 |

标准 960×540dp 电视视口：顶部区域高 86dp；导航单项宽 94dp，胶囊高 46dp；首页左右安全边距 44dp、标题区 144dp。应用卡片约 122×87dp（1.4:1）、圆角约 22dp，名称 13sp，网格六列。卡片使用细薄方向亮边、左上柔和面反射和外部投影，避免厚倒角及内侧暗框。占位字母容器使用同色系明亮渐变，真实 Logo 保留原色；焦点环独立绘制。窄于 780dp 时网格四列，较矮视口缩短标题区，导航使用紧凑宽度。所有生产单元格均由实际目录动态渲染，当前五款应用不人为补足两行。

| 用途 | 色值 / 材质 |
| --- | --- |
| 页面背景 | `#F7F8FC` |
| 正文 | `#202437` |
| 次要文字 | `#778198` |
| 流光 | `#C8B6FF`、`#A9D8FF`、`#FFD2E7` 的半透明渐变 |
| 导航容器 | 半透明白色渐变、细亮边、柔和环境投影 |
| 导航高亮 | 白色胶囊及浅投影 |
| 图标焦点边缘 | 低饱和蓝紫色，边宽与透明度平滑过渡 |
| 操作按钮 | 沿用明确的蓝色主操作和白色内容层 |

导航玻璃在 API 31+ 使用与根页面坐标对齐的壁纸副本，仅对胶囊区域的背景层进行 18dp 模糊，前景文字和图标保持清晰；另有半透明染色、双层折射亮边和浅投影。旧系统或低内存设备使用无模糊降级。流光使用烘焙后的连续丝绸曲面纹理，替换上一版仍有折线感的拼接色带；素材及最终生成提示词见[素材说明](silk-wallpaper-asset.md)。

卡片材质由 `CardMaterial.kt` 缓存生成：圆角距离控制细薄方向亮边，宽幅左上反射自然渐隐，底部仅保留微弱背光。共享单次圆角裁剪，避免叠加边缘。

圆角轮廓统一引用同一个 22dp Shape：图标与受光先在卡片大小的图层中合成，再统一裁剪一次；阴影和焦点环使用相同轮廓。避免底层约 20.6dp、光照层 22dp 的重复遮罩造成双边。背光由表面亮度衰减表达，移除底部独立暗色描线，减少底部圆角的灰边与粗糙感。

## 动效与遥控器

| 场景 | 实现 |
| --- | --- |
| 图标聚焦 | 1.08 倍、3dp 抬升；阻尼 0.86 / 刚度 560 的弹簧，可被新目标打断 |
| 图标按下 | 缩至 0.975 倍，释放回到焦点尺度；点击不等待动画结束 |
| 光影 / 名称 | 阴影约 7→16dp、柔光、边缘、名称颜色在 180–210ms 内过渡 |
| 导航 | 高亮胶囊 220ms 滑动，图标与文字 180ms 变色；确认后切换业务页面 |
| 背景 | 18 秒平滑往返，水平 ±7dp、垂直 ±3dp，仅改变合成图层属性 |
| 首次进入 | 内容 240ms 淡入、8dp 上移，不逐图标串行等待 |
| 详情进退 | 保留原有短距离水平位移与淡入淡出，旧页退出时禁止操作 |
| 弹层 | 保留 230ms 的轻微缩放进入，110–140ms 退出后移除窗口 |

导航向下进入首页上次聚焦图标；网格首行向上回到首页导航项。左右边缘不绕行，末行向下不丢焦点。连续方向键独立计算最新目标，取消过时的虚拟列表定位任务，不等待缩放或阴影动画。已加载单元格立即交接焦点并触发原生可见性滚动；尚未加载的行先定位、完成布局后设置焦点。

首页 LazyGridState 与最后应用 ID 保留在根层；当前实现返回时恢复已有目录和位置，不重新加载整页。搜索词和分类继续由路由状态容器保存。详情介绍仍是可聚焦的短段落，支持上下键完整阅读以及触摸滑动；截图预览关闭后恢复原图焦点。

## 性能与降级

- 背景纹理只解码并缓存一次；循环只更新独立图层的位移，避免逐帧重建曲线或重排网格。导航只重新采样胶囊区域，局部模糊不覆盖整个屏幕。
- 低内存设备和系统关闭动画时背景静止；离开首页时停止循环。
- 系统动画缩放为 0 时取消页面位移、弹层缩放、图标缩放及按压缩放；保留即时的边缘、柔光、名称和选中状态，焦点依然清晰。
- 光照纹理宽度最多 384px，共享最多 8 个几何 / 材质缓存；GPU 平滑放大低频光照，Logo 和唯一圆角遮罩仍按原生分辨率绘制。焦点变动不重新生成材质，不增加动态模糊。
- 图标沿用共享 Coil 内存 / 磁盘缓存及 SVG 解码；焦点变化不改变图片请求。
- 没有全屏实时模糊、粒子或持续形变。导航局部模糊在低内存设备关闭。尚未在实体电视测量 60FPS、GPU 成本和输入延迟，不能以模拟器测试代替该结论。

## 验证与证据

`StoreNavigationTest` 覆盖真实目录、顶部导航、快速切页、搜索状态、详情进退和截图预览；`HomeGridTest` 使用仅存在于测试的 42 款目录，覆盖六列快速跨行、视口可见性与屏幕下方焦点恢复；`DetailReadingTest` 保留介绍首中尾、大字号和触摸回归。

实际执行结果、安装包摘要和分辨率记录见[验证汇总](verification.json)。[首页截图](screenshots/home.png)和[交互录屏](screenshots/navigation.mp4)均取自运行中的 Android TV 模拟器。实体电视 / 盒子的性能和遥控器适配仍待实测。

统一左上光源修订：正面受光按左上至右下连续衰减，轮廓高光同时依据朝向和位置衰减；移除底部反光。停用系统定向投影，保留微弱环境阴影，自定义投影向右下偏移 11/13dp、接触阴影偏移 9/4dp。普通卡片无全周白色描边，焦点环独立。
