# 下载、身份检查与恢复（v0.3.0-dev）

下载队列仍逐任务执行；大文件最多四路分段。每个任务保存仓库来源、Release、资产 ID、URL、大小、上游摘要（可空）和资产更新时间，不依赖首页候选一直存在。

存在上游 SHA-256 时严格比对。上游缺少摘要时明确说明，完成下载后计算本机摘要供提交安装前复核，不能称为独立来源完整性比对。

无上游摘要时，续传要求强 ETag：没有可靠验证器重新下载；每段响应必须匹配范围和验证器，变化时丢弃旧进度。不支持 Range 时降级为完整单连接。已有上游摘要的路径继续支持原有 Range / If-Range 恢复并在结束核对整包。

下载后检查实际 APK 的包名、签名、minSdk、ABI 和版本；系统不兼容、降级或已安装包签名冲突不提交。任务存本机文件摘要与检查身份，首次来源确认后再次检查文件才提交 PackageInstaller，系统仍需用户确认。仅系统成功且实际包身份相符后记录关联。

安装前尝试核对官方资产是否删除或变化；联网不可用时只使用已完整检查的本地文件，并保留来源检查时间。官方明确 404、资产标识或摘要变化阻止继续安装。新流程不采用人工目录的 24 小时授权门槛。

旧任务缺少新字段时不会自动获得来源确认；保留可恢复文件，重新检查后才能安装。取消下载删除进度，网络 / 进程中断保留进度并提供手动继续。清缓存保护活动任务与等待安装文件。

验证分为 MockWebServer 的 Range / 摘要 / 验证器场景，以及仓库自有测试 APK 的系统安装升级；不代表所有真实设备或第三方软件已经测试。详见[本轮验证](tool-iteration-validation.md)。
