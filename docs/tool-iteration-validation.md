# v0.3.0-dev 工具化开发验证

日期：2026-11-11。本文区分已经实现的代码、受控测试、真实联网验证和未验证事项，不把需求文档当成全部验收已经完成。

后续请求与布局调整见 [v0.3.1-dev 记录](github-network-and-layout.md)，本页保留 v0.3.0-dev 的验收基线。

## 实现范围

| 需求 | 本轮实现 |
| --- | --- |
| T01–T03 | 公开仓库直达、持久化来源、目录外 APK 下载；可空上游摘要与可靠续传；实际包名 / 签名 / ABI / minSdk 检查、来源确认、系统安装 |
| T04–T05 | 收藏、显式订阅、安装关联与包级检查 / 渠道分离，外部安装主动关联、忽略版本、错误与成功时间保留；不自动下载或安装 |
| T06–T08 / T13–T14 | 自动发现、分类、规则推荐、平台 / 跨平台近期 Star 增量、总 Star 排序、最近发布；来源口径、限流、缓存和统一预算 |
| T09 | 旧任务新字段默认不信任、旧安装记录只读待确认提示、独立来源与任务恢复；本机数据清除、缓存清理、隐藏恢复、减少动画及自动检查设置 |
| T10 | 应用内协议、首次主动同意、拒绝不下载、版本记录、设置与开源许可入口 |
| T11 | CommonMark + GFM 表格解析，Compose 分块懒渲染；图片、链接、代码、表格、折叠内容及锚点；实际语言文件切换、偏好与缓存 |
| T12 | 详情返回来源列表回顶并保留条件 / 结果；README 子文档与图片预览按层返回 |

应用仍使用原生 Kotlin / Compose、OkHttp、Coil、原子 JSON 与 WorkManager。没有业务服务器、浏览器运行时、翻译 SDK、人工热门名单、随包第三方图标，也没有新增 QUERY_ALL_PACKAGES 权限。

为管理用户指定的可启动应用，Manifest 从固定五个包名查询改为 MAIN + LAUNCHER / LEANBACK_LAUNCHER intent 查询；程序仍按用户订阅和关联的已知包名读取，不遍历全设备应用。无可见启动入口的特殊包可能仍无法识别，界面保留限制说明。

## 数据与交互细节

- 趋势候选先显示，在总预算内渐进补全首屏五项 README / 仓库资料；缺少项目 Logo 使用明确标注的作者头像，不为补图阻塞候选首屏。
- 发现候选和用户记录分开；简略的 Trending 项目不会覆盖已取得的详情、版本、收藏和关联。首页批量持久化在后台执行，焦点变化不重新抓取或解析正文。
- 普通仓库安装不再依赖人工目录证书。上游摘要存在时严格比对；缺失时明确说明，本机摘要只用来复核文件没有在下载后被替换。
- 无上游摘要的续传要求强 ETag，每段校验范围和身份。文件改动、签名冲突、已知系统不兼容及覆盖降级不提交安装。
- 系统成功回调与实际包身份核对共同决定 INSTALLED。包可见性 / 状态传播允许有限重试；同版已装状态本身不等于本次安装成功。
- 热门默认是所选时段新增 Star，不是累计总量；首次默认本周。API 期间聚合与 Trending 期间值不混算，缺失值不是零，总量快照净差不是新增人数。数据不可用时保留缓存和显式提示，不静默替换成总 Star 榜。
- 发现刷新共用最多 12 次请求的预算、两路 API 并发与冷却；离开首页取消预取，用户打开的 README 和详情优先。缓存不是完整应用索引，低预算时结果可能较少。
- 用户记录保留 200 个最近未固定仓库，收藏 / 订阅 / 关联不随候选淘汰；发现快照最多六份，每份最多 30 个原始趋势候选；正文文件缓存最多 40 份、解析结果最多八篇，图片沿用 64 MiB 磁盘缓存。

## 工程与原生验证

构建与 Lint 通过；67 项 Android 单元测试、16 项 Python 测试通过；1080p 正常动画与 720p 减少动画各 38 项原生测试通过；受控安装升级夹具 1 项通过。另有显式真实联网诊断 1 项，记录三种传输配置与 API 的状态，不计入确定性原生测试总数。

最终结果和 APK SHA-256 见 [verification-v0.3.0.json](verification-v0.3.0.json)。可复现命令：

```bash
./scripts/check.sh
./scripts/test-tv.sh
./scripts/test-tv-720p.sh
./scripts/test-fixture-install.sh
```

- 构建检查覆盖目录历史夹具、Python README 提取测试、Android 单元测试、Lint、应用与原生测试包；测试安装夹具为独立 Gradle 模块，不打入商店安装包。
- 原生测试使用受控网络接口，覆盖遥控器焦点、搜索分页、深层列表返回回顶、直达、协议拒绝、版本菜单、长文末尾、真实语言文件切换、缓存恢复、来源检查和用户记录持久化。
- 显式安装脚本只操作 emulator-5554，安装本仓库自有约 6 KiB 的 1.0 / 2.0 APK，验证系统确认、未知目录包首次安装、同签名升级、关联落盘和降级拦截，结束卸载测试夹具；不等同本轮重新验证第三方应用实际安装。
- 约 112 KiB 长文的解析 / 缓存耗时记录由原生测试输出。该指标不包含联网、图片解码或首帧，也不是 FPS 结论。

## 体积与解析样本

基线 APK 大小与增量见 verification-v0.3.0.json；相对 v0.2.2-dev 的 20,643,439 字节基线，整轮功能净增不到 1 MiB，满足初始 2 MiB 阅读功能预算的量级目标。该对比是相同 debug 构建的整轮净变化，不是对每个功能单独分摊。

本轮 114,660 字节长文样本首次解析约 189.8 ms、已解析结果缓存命中约 0.69 ms。来自 API33 模拟器，不包括联网、图片或首帧时间，不代表所有文件和真实硬件表现。

## 真实联网验证

本轮只读请求验证 GitHub 官方匿名 `stargazers/history` 可用，返回按日聚合数据；Trending 周榜页面可访问并包含项目条目。正文与版本解析、排序、语言和失败分支另由确定性测试覆盖。模拟器联网检查曾出现 TLS 握手 `connection closed`，默认连接、HTTP/1.1 与 TLS1.2 当时均失败；后续相同 Android 运行时三种配置与 API 均返回 200。没有禁用证书校验、硬编码 IP 或引入应用内代理。此波动与受控协议测试分开记录，不承诺目标设备网络始终可达。

最终[真实热门页截图](screenshots/tool-global-hot.png)显示了 Trending 本周的 14 个候选，并按来源新增 Star 排序。此次运行部分仓库资料请求遇到 GitHub 匿名限流，页面保留趋势结果并提示资料未补全；已加载的作者头像与字母占位不冒充项目 Logo。本轮不声称所有候选的 README 图标均已实网加载成功。

真实运行截图和安装包版本以最终产物为准，不能把受控假接口结果当成全站实时数据。

## 仍需验证的发行边界

- 尚无本轮实体电视 / 盒子矩阵，不宣称达到实体设备 60FPS、特定输入延迟或所有 Android 版本兼容。
- 720p / 减少动画的模拟器验证不替代低内存设备、实际存储不足、厂商休眠与长期后台调度测试。
- README 不执行脚本；复杂图表、公式、视频等保留文本 / 代码或原文入口，不保证完整复刻 GitHub 页面。多语言只发现实际文件与语言链接，不保证穷举整个仓库。
- 不支持 Split APK / XAPK / AAB，不实现其他平台的本机安装。外部应用关联需要用户先提供对应仓库并下载 APK 核对身份，不能仅凭名称自动配对。
- Trending 是页面适配，源站结构和访问条件变化可能需要软件修复；没有完整全站候选或自营历史采集服务，不承诺全站精确榜单。Star 历史按源站日历解释，不能冒称滚动 24 小时。
- 正式发行签名、跨版本自更新、发行地区协议核定与至少两台实体设备验收仍是公开发行前工作。当前为开发 APK；没有自动发布正式 Release。
