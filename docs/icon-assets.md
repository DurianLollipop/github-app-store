# 在线图标与磁盘缓存

第三方应用图标不随 APK 打包。APK 只保存图标 URL，运行时通过 Coil 在线加载，支持 SVG / PNG 等格式；图片缓存位于设备的 `cacheDir/image_cache`，上限 64 MiB，自动淘汰旧内容。已缓存的图片可在缓存仍有效时复用，不必重复下载；首次访问或缓存已被清理且无网络时显示字母回退。

推荐目录优先使用 README 中的真实应用 Logo，README 无 Logo 的三个项目使用官方仓库发布素材的在线地址。全站搜索先使用 GitHub 返回的仓库作者头像，打开详情后若 README 识别到应用 Logo，则更新为应用 Logo。头像回退不代表应用自己的官方图标。

清理缓存会清理设备图片缓存，不修改推荐目录，也不会将缓存重新打入 APK。原有 `assets/icons`、`BundledIcons` 和静态图标同步打包脚本已移除。

图片及品牌属于相应项目权利人，URL 来源保留在目录或 GitHub / README 返回数据中。
