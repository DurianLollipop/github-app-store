# 图标来源与缓存

v0.3.1-dev 不随安装包保存第三方应用图标。项目 README 中识别到的 Logo 优先，未识别时保留 GitHub 作者头像；头像会在无障碍描述和详情中标明，不冒称项目图标。加载失败显示字母占位。

跨平台趋势候选先展示，在共享额度与额外补全预算内，仅对可见网格项目渐进补充仓库资料与 README；滚动后再补充新进入视口的项目。其余项目先使用官方作者头像地址，进入详情时获取完整资料；不为整个候选池预抓全部截图，也不因补全图标延迟候选首屏。

所有图片通过共享 Coil 加载和按尺寸解码，磁盘缓存上限 64 MiB；清缓存不会删除用户收藏、订阅和包身份关联。加载 URL 相同的焦点变化不重新请求图标。

历史 `catalog/sources.json` 保留开发样本的 README 与官方素材来源，用于原目录脚本和测试夹具，不是自动发现应用的必需运营清单。v0.2.1 曾随包保存五款图标，v0.2.2 已移除；当前 APK 仍验证无 `assets/icons/` 或第三方 APK 文件。
