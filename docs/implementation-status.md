## 已验证的环境与规则

- JDK 17、Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、Android SDK / Build Tools 35。
- Android TV API 33 ARM64 模拟器，1920×1080；不是实体电视测试结果。
- 单元测试覆盖选包歧义、SDK / ABI 过滤、versionCode 比较、签名冲突、下载损坏、缺少摘要、上游 404、目录签名篡改及防回退。
- 原生导航测试覆盖详情与返回、方向键进入内容区、搜索筛选与无结果、下载中心空状态。
- 实际官方 APK 检查发现 Android 13 的归档解析器仅在同时提供 `GET_SIGNATURES` 时收集证书；已兼容处理，API 28+ 仍读取当前 `SigningInfo.apkContentsSigners`，不改为信任旧证书。[Android 13 官方源码](https://android.googlesource.com/platform/frameworks/base/+/refs/tags/android-13.0.0_r1/core/java/android/content/pm/PackageManager.java)

本轮结果：22 项单元测试、Android Lint 与 APK 构建通过；4 项原生导航测试通过；TV Bro 官方 APK 的真实下载、文件与签名校验、系统安装确认及已装版本核对通过。回归脚本保存在 `scripts/`，最终界面截图保存在 `docs/screenshots/`。

后续 README 资料接入：五个项目的介绍已从其官方 README 同步，Jellyfin 与 NewPipe 有 Logo；LocalSend 有 2 张截图、NewPipe 收录 8 张、Material Files 有 6 张；Jellyfin 保留两张原有官方文章截图。LocalSend / Material Files 使用官方中文 README，其余保留英文原文。提取过程记录原文 URL、抓取时间和内容 SHA-256，仅影响展示字段，不刷新安装包审核时间或信任证书。

资料接入后的验证：16 项 Python 提取与同步测试、23 项 Android 单元测试、Android Lint、APK 构建及 4 项原生导航测试通过；详情页 README 来源入口已验证。本轮未重复真实下载安装测试，上述安装链路结果属于上一轮验证。

视觉与动效调整后：统一浅色主题，首页横幅可随文字增高；页面与弹层加入短促过渡，离场页禁止操作，保存搜索状态并恢复返回焦点。正常动画和系统关闭动画两种模式各通过 7 项原生回归，新增覆盖连续打断切页、详情返回后再次遥控进入、搜索状态保留以及截图弹层关闭后回到原图。配色与动效参数记录在[界面设计记录](ui-design.md)。当前截图反映新版界面，系统安装确认图保留前期真实验证记录。

0.1.1-dev 修复详情介绍无法用遥控器浏览：原正文不可聚焦，方向键会跳过介绍内容。现改为可聚焦的阅读段落，长段落在句子或单词边界拆分；外层列表随焦点移动滚动，触摸滑动保持可用。另修复从介绍中段退出后重新进入时，列表恢复到中段、顶部初始焦点尚未加载而报错的问题：重新打开时先回到顶部再设置焦点。新增回归直接发送方向键并检查介绍字符实际进入视野，覆盖开头、中段、末段、大字号和触摸输入，不再用程序化滚动代替遥控器可用性验证。

0.2.0-dev 首页改造：沿用 Compose、ViewModel / StateFlow 和原有路由，替换侧栏与宣传横幅为顶部胶囊导航和六列图标网格。真实 Logo 改用中性容器；图标聚焦支持 1.08 倍缩放、3dp 抬升、柔光和可中断弹簧。经参考图校正，背景改用烘焙的连续丝绸曲面纹理，保留 18 秒合成图层位移，低内存 / 关闭动画时静止；导航在 API 31+ 使用背景副本局部模糊，旧系统和低内存设备保留材质降级。应用卡片改为 1.4:1 横向圆角并采用统一左上光源、朝光边缘反射和右下软投影，去掉四周持续发亮的描边。修复顶部导航初次布局焦点、虚拟网格快速跨行目标衔接和搜索空状态可用空间。

## 与原计划的实施差异

1. **存储**：首轮使用原子 JSON 与本地偏好设置，避免在目录很小时引入额外数据库迁移；保持数据层接口，后续按规模迁移 Room / DataStore。
2. **下载调度**：当前采用带通知的前台 dataSync 服务，并处理长任务超时。UIDT 分支与 Range / ETag 续传仍待新增系统版本和网络矩阵验证。
3. **目录部署**：已实现可选签名远程目录的协议和客户端验证，但尚未部署托管地址、接入正式目录公钥或建立生产签名流程。
4. **发行基线**：先固定已完成构建验证的 API 35 组合；公开发行前应重新核对最新 targetSdk 要求并完成升级验证。
5. **应用数量**：目前 5 个开发样本、2 个有真实 APK 审核记录，未达到公开测试目标 20–30 个。

- 实际运行每个历史版本选择与升级路径；当前内置仅两个应用的各一个版本，可在线查询更多版本。

- 正式发布签名、商店自身从旧版到新版的真实更新测试。
- 在 Android 8、较新 Android TV 及目标网络环境验证后台限制、存储不足与性能目标。
- 上线前整理隐私说明、发行说明和安装指南。
